# 01-cursos

Material de estudos organizados por curso. Cada curso tem estrutura padronizada para facilitar navegação e aplicação ao TCC.

## Estrutura de Cada Curso

Cada curso deve conter:
- **README.md**: Informações sobre o curso, progresso, índice
- **progresso.md**: Checklist de seções/módulos concluídos
- **notas/**: Anotações por tópico (usar template-nota-curso.md)
- **exercicios/**: Soluções de exercícios práticos
- **notebooks/**: Jupyter notebooks exploratórios
- **projetos/**: Projetos práticos do curso
- **aplicacao-no-tcc.md**: Como o curso se conecta com o TCC

## Dicas de Estudo

1. **Consistência**: Estude um pouco todo dia em vez de muito de uma vez
2. **Aplicação**: Sempre pense como aplicar ao TCC
3. **Notas**: Use templates para padronizar anotações
4. **Prática**: Faça todos os exercícios, não apenas assista
5. **Conexões**: Relacione conceitos entre cursos diferentes
