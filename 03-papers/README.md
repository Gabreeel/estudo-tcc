# 03-papers

Revisão bibliográfica sistemática, fichamentos e análise crítica da literatura.

## Estrutura

### fichamentos/
Fichamentos individuais de papers usando [template-fichamento-paper.md](../templates/template-fichamento-paper.md):
- Um arquivo por paper
- Nome do arquivo: `Autor-Ano-titulo-curto.md`
- Categorizado por tags

### Documentos de Síntese
- **revisao-bibliografica.md**: Síntese geral da literatura
- **matriz-de-comparacao.md**: Comparação sistemática de abordagens
- **perguntas-em-aberto.md**: Gaps e oportunidades de pesquisa
- **timeline.md**: Evolução cronológica da área

## Categorias de Papers

### Visual Classification
Papers que usam representação visual de binários para classificação.

### End-to-End
Abordagens end-to-end que processam diretamente binários.

### Adversarial ML
Robustez contra ataques adversariais em malware detection.

### Explainability (XAI)
Técnicas para interpretar decisões de modelos.

### Multi-modal
Combinação de múltiplas representações ou features.

### Surveys
Revisões sistemáticas e surveys da área.

## Processo de Fichamento

1. **Leitura Rápida**: Abstract, introdução, conclusão (15 min)
2. **Decisão**: Vale aprofundar? Relevância para TCC?
3. **Leitura Completa**: Se relevante, ler tudo com atenção (1-2h)
4. **Fichamento**: Usar template, foco em aplicabilidade (30-45 min)
5. **Conexões**: Relacionar com outros papers e experimentos

## Metas

- [ ] 10-15 papers principais fichados
- [ ] Matriz de comparação completa
- [ ] Identificar 3-5 gaps de pesquisa
- [ ] Definir baseline a partir da literatura

## Dicas de Leitura

1. **Não leia linearmente**: Abstract → Conclusão → Figuras → Introdução → Resto
2. **Foque em aplicabilidade**: Sempre pergunte "como isso ajuda meu TCC?"
3. **Compare abordagens**: Use matriz de comparação
4. **Conecte papers**: Identifique citações cruzadas e evolução de ideias
5. **Código disponível?**: Priorize papers com código open-source
