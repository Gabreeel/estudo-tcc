# 00-planejamento

Esta pasta contém documentos de planejamento, organização e gestão do projeto de TCC.

## Conteúdo

### Documentos de Gestão
- **cronograma.md**: Timeline detalhada do projeto
- **tarefas.md**: Lista de tarefas e checklist
- **reunioes.md**: Notas de reuniões com orientador

### Planejamento Acadêmico
- **proposta-inicial.md**: Primeira versão da proposta
- **escopo.md**: Definição de escopo e limitações
- **metodologia.md**: Metodologia de pesquisa

### Reflexões
- **diario.md**: Diário de desenvolvimento (opcional)
- **decisoes.md**: Registro de decisões importantes
- **licoes-aprendidas.md**: Insights ao longo do projeto

## Como Usar

1. Mantenha cronograma atualizado semanalmente
2. Registre decisões importantes (ex: por que escolheu dataset X)
3. Documente mudanças de escopo e justificativas
4. Use para organizar reuniões e definir prioridades
