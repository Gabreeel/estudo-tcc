# Glossário

## Termos de Baixo Nível

**Assembly**: Linguagem de programação de baixo nível que representa instruções de máquina de forma legível.

**Disassembly**: Processo de converter código de máquina (binário) de volta para Assembly.

**Engenharia Reversa**: Análise de software para compreender sua estrutura e funcionamento sem acesso ao código-fonte.

**GDB**: GNU Debugger, ferramenta de debugging para programas em C/C++/Assembly.

**Ghidra**: Framework de engenharia reversa desenvolvido pela NSA.

**Magic Bytes**: Sequência de bytes no início de um arquivo que identifica seu formato (ex: 0x4D5A para PE).

**NASM**: Netwide Assembler, montador para Assembly x86.

**PE (Portable Executable)**: Formato de arquivo executável do Windows (.exe, .dll).

**Registrador**: Pequena unidade de armazenamento na CPU (ex: EAX, EBX, ESP).

**x86/x64**: Arquiteturas de processadores Intel/AMD de 32 e 64 bits.

## Termos de Análise de Malware

**Análise Dinâmica**: Executar malware em ambiente controlado para observar comportamento.

**Análise Estática**: Analisar malware sem executá-lo, estudando código e estrutura.

**C&C (Command and Control)**: Servidor usado por malware para receber comandos.

**Família de Malware**: Grupo de malwares que compartilham características e origem.

**Payload**: Código malicioso principal que executa a ação prejudicial.

**Sandbox**: Ambiente isolado para executar código suspeito com segurança.

**Assinatura**: Padrão único que identifica um malware específico.

## Termos de Machine Learning

**Baseline**: Modelo simples usado como referência para comparação.

**CNN (Convolutional Neural Network)**: Rede neural especializada em processar dados com estrutura de grid (imagens).

**Dataset**: Conjunto de dados usado para treinar e testar modelos.

**Feature**: Característica extraída dos dados usada como entrada do modelo.

**Overfitting**: Modelo que memoriza dados de treino mas falha em generalizar.

**PyTorch**: Framework de Deep Learning desenvolvido pelo Facebook.

**Split**: Divisão do dataset em conjuntos de treino, validação e teste.

**XAI (Explainable AI)**: Técnicas para interpretar decisões de modelos de IA.

## Termos de Deep Learning

**Autograd**: Sistema de diferenciação automática do PyTorch.

**Backpropagation**: Algoritmo para calcular gradientes em redes neurais.

**Epoch**: Uma passagem completa pelo dataset de treino.

**Grad-CAM**: Técnica de visualização que mostra regiões importantes para a decisão da CNN.

**Loss Function**: Função que mede o erro do modelo durante treino.

**Tensor**: Estrutura de dados multidimensional usada no PyTorch.

## Métricas

**Accuracy**: Taxa de acertos do modelo.

**F1-Score**: Média harmônica entre precision e recall.

**Precision**: Proporção de predições positivas que estão corretas.

**Recall**: Proporção de casos positivos que foram identificados.

**Confusion Matrix**: Tabela que mostra acertos e erros por classe.
