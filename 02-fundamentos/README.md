# 02-fundamentos

Conhecimento consolidado e organizado por área. Diferente de `01-cursos` (material bruto de estudo), esta pasta contém sínteses, resumos e referências rápidas.

## Estrutura

### baixo-nivel/
Fundamentos de arquitetura, Assembly, engenharia reversa:
- **registradores.md**: Guia rápido de registradores x86/x64
- **instrucoes-assembly.md**: Instruções Assembly mais comuns
- **pe-format.md**: Estrutura de arquivos PE (Windows)
- **elf-format.md**: Estrutura de arquivos ELF (Linux)
- **calling-conventions.md**: Convenções de chamada
- **debugging-cheatsheet.md**: Comandos GDB essenciais

### malware-analysis/
Fundamentos de análise de malware:
- **tecnicas-analise.md**: Estática vs Dinâmica
- **indicadores-malware.md**: Comportamentos suspeitos
- **familias-conhecidas.md**: Principais famílias de malware
- **sandboxes.md**: Ferramentas e uso de sandboxes
- **evasion-techniques.md**: Técnicas de evasão

### ia-e-dados/
Fundamentos de ML e DL aplicados ao problema:
- **ml-basico.md**: Conceitos fundamentais de ML
- **cnn-fundamentos.md**: Como CNNs funcionam
- **pytorch-essentials.md**: PyTorch essencial
- **metricas.md**: Métricas de avaliação
- **preprocessing.md**: Técnicas de pré-processamento
- **xai-tecnicas.md**: Técnicas de explainability

## Objetivo

Esta pasta serve como **referência rápida** consolidada, não como material de estudo linear. Use quando:
- Precisa lembrar um conceito específico
- Quer uma visão geral de um tópico
- Está escrevendo o TCC e precisa de definições
- Quer conectar conceitos de áreas diferentes

## Como Consolidar Conhecimento

1. Após completar um módulo de curso, crie/atualize um arquivo aqui
2. Sintetize em linguagem própria (não copie)
3. Foque no essencial para o TCC
4. Inclua exemplos práticos
5. Conecte com outros fundamentos
